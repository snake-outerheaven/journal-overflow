# Todo

## Criar um pequeno projeto em C que:

1) Calcule o enésimo termo de uma P.A
2) Calcule a soma de n termos de uma P.A:
3) Interpole k números em uma P.A
4) Gere uma P.A. de segunda ordem a partir de uma sequência de 8 termos. Use um vetor para armazenar a sequência original.

O programa deve ter um menu onde o usuário escolha o que fazer, tendo funções caso seja necessário. o envio do trabalho deve ser no AVA.
